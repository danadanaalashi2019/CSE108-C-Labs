# Lab 12

## Course
CSE108 – Introduction to Algorithm and Programming

## Description
This lab focuses on implementing a **Binary Search Tree (BST)** in C. The program reads integer values from a file, inserts them into the tree recursively, and performs various operations to analyze and traverse the tree.

## Topics Covered
- Binary Search Trees (BST)
- Recursion
- Dynamic Memory Allocation
- File Handling
- Tree Traversal
- Search Algorithms

## Files
- `lab12.c` – My implementation for Lab 12.
- `numbers.txt` – Input data used to build the binary search tree.
- `Assignment.pdf` – Lab assignment provided by the instructor.

## How to Compile

```bash
gcc lab12.c -o lab12
```

## How to Run

```bash
./lab12
```

On Windows:

```bash
lab12.exe
```
